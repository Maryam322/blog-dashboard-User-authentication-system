# blog-dashboard-User-authentication-system
This project is a Django web application that implements a fully custom user authentication system along with a blog management system. The application  provides a complete login and regist:ration. The system allows users to register, log in using email instead of username, and manage blog posts.
How to Run the Project:

cd project-name

python -m venv venv

venv\Scripts\activate

pip install django

python manage.py migrate

python manage.py runserver
